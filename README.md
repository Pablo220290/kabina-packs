# Kabina · packs de escenas

Imágenes de vehículos integrados en paisajes de Paraguay para el launcher Kabina. Cada pack corresponde a un modelo y color.

- `indice.json`: lista de packs disponibles con versión, tamaño y verificación (sha256).
- `packs/<modelo>/<color>.zip`: las escenas del pack (`escenas/<lugar>/<momento>.webp`) y su `pack.json`.
- `packs/<modelo>/<color>.jpg`: miniatura del vehículo.
